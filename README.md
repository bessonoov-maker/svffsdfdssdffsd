# YouTube Uploader

Небольшое веб-приложение, которое позволяет выбрать ролик на компьютере и загрузить его на ваш YouTube-канал через официальное API.

## Как запустить

1. Создайте OAuth-клиент в [Google Cloud Console](https://console.cloud.google.com/):
   - API & Services → Library → включите **YouTube Data API v3**.
   - API & Services → Credentials → Create Credentials → OAuth Client ID.
   - Тип приложения: **Web application**.
   - Authorized redirect URI: `http://localhost:3000/oauth2callback`.

2. Создайте файл `.env` на основе `.env.example` и заполните значения.

3. Установите зависимости и запустите сервер:

```bash
npm install
npm start
```

4. Откройте `http://localhost:3000` и нажмите «Подключить YouTube».

## Если видите “Cannot GET /”

- Убедитесь, что вы запускаете `npm start` из корня проекта (где находятся `server.js` и папка `public`).
- Проверьте, что сервер запущен именно через Node/Express, а не через простой статический сервер.

## Возможности

- Авторизация через OAuth 2.0.
- Загрузка нескольких видео с указанием названия, описания и приватности.
- Планирование времени публикации для каждого ролика (через поле даты и времени).
- Подключение нескольких каналов и выбор канала для каждого загружаемого ролика.
- Индивидуальные название и описание для каждого ролика.
- Опциональный прокси для каждого подключаемого аккаунта.
- Режим “Черновик” загружает ролик на канал, но оставляет его непубличным без расписания.
- Быстрый статус авторизации.

## Примечания

- После загрузки видео ID будет показан в интерфейсе.
- Для планируемой публикации YouTube требует приватный статус, поэтому при заданном времени публикации ролик отправляется как private.
- Подключенные каналы и токены сохраняются локально в файле `data/channels.json` и восстанавливаются при старте.
- Базовые настройки выбранных аккаунтов сохраняются в `data/settings.json`.

## Instagram (подготовленная инфраструктура)

- В интерфейсе можно сохранить Instagram Account ID и Access Token.
- Можно указать прокси для подключения Instagram аккаунта.
- Данные сохраняются в `data/instagram.json`.
- Эндпоинт `POST /instagram/publish` добавлен как заготовка: требуется настройка Instagram Graph API перед реальной публикацией.

## TikTok (подготовленная инфраструктура)

- В интерфейсе можно сохранить TikTok Account ID и Access Token.
- Можно указать прокси для подключения TikTok аккаунта.
- Данные сохраняются в `data/tiktok.json`.
- Эндпоинт `POST /tiktok/publish` добавлен как заготовка: требуется настройка TikTok API перед реальной публикацией.

## Базовые настройки

- В разделе «Базовые настройки» можно выбрать каналы/аккаунты YouTube, Instagram и TikTok, куда нужно публиковать контент.
- Выбранные аккаунты сохраняются в `data/settings.json`.
