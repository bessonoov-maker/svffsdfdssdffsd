Инструкции

  1. Подключите YouTube аккаунт через кнопку авторизации.
  2. При необходимости подключите Instagram и TikTok аккаунты.
  3. В «Базовых настройках» отметьте аккаунты, куда нужно отправлять контент.
  4. Выберите видеоролики и задайте названия, описания и время публикации.
  5. Если выбран режим «Черновик», ролик загрузится без публикации.
  6. Нажмите «Загрузить на YouTube» и дождитесь статуса завершения.

Лог событий

Возможности

  • Подключение нескольких аккаунтов YouTube, Instagram и TikTok.
  • Массовый выбор аккаунтов для публикации через базовые настройки.
  • Загрузка нескольких видео с индивидуальными названиями и описаниями.
  • Планирование публикаций с автозаполнением каждые 4 часа.
  • Режим «Черновик» для загрузки без публикации.
  • Опциональный прокси для подключения аккаунтов.

Примечания

  • Для планирования YouTube требует приватный статус до даты публикации.
  • Выбранные аккаунты для публикации сохраняются в базовых настройках.
  • Черновик загружается на канал без публикации и уведомлений.
  • Подключенные каналы и токены сохраняются локально и восстанавливаются при старте.
